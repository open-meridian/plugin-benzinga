# Pages

Both pages are under **Manage**, for the plugin's admins. Neither shows a
dividend.

## Connection

How the plugin reaches Benzinga: whether the key is set (never its value),
the pace it keeps, the requests made and Benzinga's refusals, and the last
check and why it failed if it did.

## Datasets

What the plugin serves the lake, in tabs:

- **Served**: the dividends dataset, whether it is licensed, and what was
  recorded and declined.
- **Wants**: what readers asked for and how each was answered.
- **Tickers**: each ticker read, with the security it resolved to or why
  there is none. Searchable.
- **Not recorded**: calendar rows the plugin did not record, by reason.
- **Terms**: Benzinga's terms in words.
